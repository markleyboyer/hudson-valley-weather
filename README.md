# Hudson Valley Academy Weather Records, 1827–1860

Scanned daily weather reports that academies in the Hudson Valley sent to the New York State Regents,
and an explanation of how they are being transcribed with AI checked by people.

- Browse the pages: https://markleyboyer.github.io/hudson-valley-weather/
- Map of the academies and today's NYS Mesonet stations: https://markleyboyer.github.io/hudson-valley-weather/map.html
- How the AI transcription works: https://markleyboyer.github.io/hudson-valley-weather/how-it-works/

This site is generated by `viewer/build_hudson_valley.py --site` in the WeatherTranscriber project;
edit there, not here.
